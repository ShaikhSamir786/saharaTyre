# 2. SVG contrast problems

Lighthouse found multiple SVG icons with insufficient contrast.

From your screenshot, likely candidates include:

* Navbar icons
* Floating call button icon
* Floating WhatsApp button icon
* Social media icons
* Footer icons
* Decorative icons

## Important distinction

### Decorative SVG

If the SVG is purely decorative:

```jsx
<Icon aria-hidden="true" />
```

This removes it from screen readers.

### Meaningful SVG

If the SVG provides important information, give it an accessible name:

```jsx
<svg
  role="img"
  aria-label="Phone"
>
```

However, for most icon buttons, the **button should have the label**, while the SVG should be hidden:

```jsx
<button aria-label="Call Sahara Tyre">
  <Phone aria-hidden="true" />
</button>
```

# Recommended reusable component for icon buttons

Since you're using React/Next.js, I recommend creating a reusable component.

```tsx
interface IconButtonProps {
  label: string;
  children: React.ReactNode;
  onClick?: () => void;
}

export function IconButton({
  label,
  children,
  onClick,
}: IconButtonProps) {
  return (
    <button
      onClick={onClick}
      aria-label={label}
      className="min-h-[44px] min-w-[44px] flex items-center justify-center"
    >
      {children}
    </button>
  );
}
```

Usage:

```tsx
<IconButton label="Call Sahara Tyre">
  <Phone aria-hidden="true" />
</IconButton>
```

# 1. Most important: Select elements do not have labels

The Lighthouse text says:

> **Select elements do not have associated label elements**

This means you likely have something similar to:

```jsx
<select>
  <option>Select Tyre Size</option>
</select>
```

## ❌ Don't rely only on placeholder/default option

```jsx
<select>
  <option>Select Vehicle Type</option>
</select>
```

## ✅ Correct solution

```jsx
<label htmlFor="vehicle-type">
  Vehicle Type
</label>

<select id="vehicle-type" name="vehicleType">
  <option value="">Select Vehicle Type</option>
  <option value="car">Car</option>
  <option value="bike">Bike</option>
  <option value="truck">Truck</option>
</select>
```

### If you don't want a visible label

Use an accessible label:

```jsx
<select
  aria-label="Select vehicle type"
  name="vehicleType"
>
  <option value="">Select Vehicle Type</option>
  <option value="car">Car</option>
</select>
```

### Best approach

```jsx
<label htmlFor="tyre-size" className="sr-only">
  Select tyre size
</label>

<select id="tyre-size" name="tyreSize">
```

This is especially useful if your design doesn't have visible labels.
